# Engineering Reference

Quick-lookup tables and decision guides distilled from the knowledge base
articles. Each page is written to be printed, pinned to a workstation, or used as
a first-pass specification sheet.

## Available references

The reference library covers alloy selection, tolerance and surface-finish
specification, a casting-defect catalogue, CNC capability charts, material
selection logic, an OEM supplier-audit checklist, a DFM checklist, and two
automotive-focused guides (structural die casting and EV housing manufacturing).

Downloadable, spreadsheet-ready versions of every table are available from the
[Downloads](/downloads/) section.

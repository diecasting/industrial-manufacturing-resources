An open, peer-reviewable knowledge base for **industrial manufacturing engineering**. It is
written for design engineers, manufacturing engineers, tooling engineers and sourcing
professionals who need defensible numbers, not marketing copy.

The library currently covers:

- **Aluminum die casting** and **magnesium die casting** (high-pressure, low-pressure, vacuum-assisted)
- **CNC machining** (milling, turning, 5-axis, DFM, tolerances and GD&T)
- **Tooling** (die casting dies, injection molds, tool steels, maintenance, tryout)
- **Automotive manufacturing** (lightweighting, IATF 16949, APQP/PPAP, EV enclosures, megacasting)
- **Materials** (Al, Mg and Zn die casting alloys, heat treatment, surface treatment)
- **Supplier selection** (audits, RFQ packages, tooling ownership, inspection and acceptance)

Every article follows the same structure: an SEO-optimised title, an introduction, a
technical explanation, an engineering-parameters table with real numeric ranges,
manufacturing considerations, common mistakes, related articles and references.

## How to use this repository

- Browse by topic folder (links below). Each folder has an `index.md` listing its articles.
- Each article is a standalone Markdown file with YAML front matter (`title`, `description`,
  `keywords`, `category`, `reading_time`, `last_updated`).
- Use the `## Related Articles` links at the bottom of each page to move between topics.
- Contributions are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
